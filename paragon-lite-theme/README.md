# Paragon Lite WordPress Theme

A responsive and modern WordPress theme with:

- Blog index, single post, page, archive, search, and 404 templates
- Mobile-first navigation with accessible toggle behavior
- Sidebar widget area plus primary and footer menus
- Customizer settings for accent color and container width
- `theme.json` defaults for block editor customization
- Comments support, skip link, focus styles, and reduced-motion support
- Lightweight assets and cache-friendly versioning via file modification time

## Installation

1. Copy the `paragon-lite-theme` folder into `wp-content/themes/`.
2. Activate **Paragon Lite** from WordPress admin.
3. Configure menus, widgets, logo, and style options under Appearance → Customize.
