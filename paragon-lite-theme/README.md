# Paragon Lite WordPress Theme

A simple, complete WordPress theme with:

- Blog index and archive templates
- Single post and page templates
- Sidebar widget area
- Primary and footer menus
- Search and 404 templates
- Comments support

## Installation

1. Copy the `paragon-lite-theme` folder into `wp-content/themes/`.
2. Activate **Paragon Lite** from WordPress admin.
3. Optionally configure menus, widgets, and logo under Appearance.
